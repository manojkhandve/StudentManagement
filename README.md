

This is a full-stack application for managing student records. The project includes both frontend and backend components. The backend is built using Java, while the frontend is developed using HTML, TypeScript, and CSS.

## 📁 Project Structure

```
StudentManagement/
├── Frontend/
│   └── ecommerce-frontend/     # Frontend using HTML, TypeScript, CSS
└── StudentMangementBackend/    # Backend using Java
```

---

## 🚀 Features

- Add, update, and delete student records
- Admin dashboard to view all students
- Validation for student information
- Responsive user interface

---

## 🧰 Technologies Used

### Backend:
- Java
- JDBC (assumed based on standard Java DB handling)
- MySQL or similar RDBMS (assumed)

### Frontend:
- HTML
- TypeScript
- CSS

---

## 🛠️ Setup Instructions

### Clone the repository

```bash
git clone https://github.com/manojkhandve/StudentManagement.git
cd StudentManagement
```

---

### Backend Setup

1. Navigate to the backend folder:
   ```bash
   cd StudentMangementBackend
   ```

2. Compile and run the Java files:
   ```bash
   javac Main.java
   java Main
   ```

> Ensure Java and your DB server are properly configured.

---

### Frontend Setup

1. Navigate to the frontend folder:
   ```bash
   cd Frontend/ecommerce-frontend
   ```

2. If using a framework like Angular (based on TypeScript usage), install dependencies:
   ```bash
   npm install
   ```

3. Start the frontend server (adjust if Angular, React, or other tools are used):
   ```bash
   npm start
   ```
